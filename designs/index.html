Payouts — functional specification

MC
Maya Chen · edited 2m ago · v14
This spec is shared with the Northwind client. Engineering details live in collapsible blocks.

Overview

Payouts lets merchants move settled balances to a destination bank account on a configurable schedule. This spec covers scheduling, batch execution, reconciliation, and failure handling for the GA release.

Requirements

  • Merchants schedule payouts daily, weekly, or manual trigger.
  • Each payout is idempotent — a repeated request with the same key returns the original result.
  • Failed payouts retry with exponential backoff, max 5 attempts.
  • Reconciliation runs hourly and surfaces mismatches within 15 minutes.

Acceptance criteria

  • POST /payouts with a duplicate idempotency key returns 200 with the cached payout.
  • P99 payout initiation latency under 800ms at 500 RPS.
  • Zero data loss across a regional failover during execution.
